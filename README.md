# Lab Programación III - Sistema Integrado (INF5170)

## 📝 Descripción

Aplicación web que integra múltiples ejercicios del laboratorio, incluyendo:

- Sistema de autenticación (Login/Registro)
- Formulario multi-paso con almacenamiento en base de datos NoSQL
- Validador de cédula dominicana (Algoritmo Módulo 10)
- Menú dinámico generado con JavaScript

## ✅ Requisitos Cumplidos

1. ✅ Proceso de login con usuario y contraseña (Firebase Auth)
2. ✅ Formulario multi-página que almacena información en Firestore (NoSQL)
3. ✅ Menú dinámico generado con JavaScript
4. ✅ Montado en la Web (GitHub Pages)
5. ✅ Lenguaje: HTML5, CSS3, JavaScript
6. ✅ Uso de Inteligencia Artificial como apoyo en el desarrollo
7. ✅ Código documentado y versionado en GitHub
